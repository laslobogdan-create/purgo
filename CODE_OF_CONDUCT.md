# Code of conduct

Purgo welcomes everyone who wants to use, report problems with, or improve the project.

- Be respectful and constructive. Criticise code and ideas, not people.
- No harassment, insults, discrimination or personal attacks, in any form.
- Keep discussions on topic and assume good intentions.
- Do not post other people's private information.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem, contact the maintainer through a GitHub issue or the email on their GitHub profile.
